# Fashion-MNIST Analysis

This project focuses on exploratory data analysis and classical machine learning models applied to the Fashion-MNIST dataset.

The goal of the project is to understand the structure of the data, extract meaningful features, and evaluate the performance of several supervised learning algorithms on an image classification task.

## Dataset
Fashion-MNIST is a dataset of grayscale images (28x28 pixels) representing different categories of clothing items, such as shirts, shoes, bags, and coats.  
Each image is labeled with one of 10 possible classes.

## Methodology
The project includes the following steps:
- Data loading and preprocessing
- Feature normalization and dimensionality reduction
- Visualization of samples and data distributions
- Training and evaluation of multiple machine learning models
- Comparison of model performance using accuracy and other metrics


## Conclusion
This project demonstrates how classical machine learning techniques can be applied to image-based datasets and provides insights into the strengths and limitations of different models.
